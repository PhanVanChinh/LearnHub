# Nhạc nền

Thả file nhạc vào thư mục này (`.mp3`, `.m4a`, `.ogg`, `.wav`, `.webm`) là thanh nhạc trên cùng tự hiện.
Không có file nào → thanh nhạc ẩn hoàn toàn.

- Tên file thành tên bài hiển thị: `01 - Lofi Chill.mp3` → "Lofi Chill" (số thứ tự và gạch nối được bỏ).
- Danh sách đọc **lúc build**: thêm file xong chạy lại `npm run dev`, hoặc build lại site tĩnh.
- File nằm trong repo và được deploy lên GitHub Pages, nên giữ dung lượng nhỏ (nén 96–128 kbps, mỗi bài vài MB).
- Chỉ dùng nhạc bạn có quyền phát: nhạc miễn phí bản quyền (YouTube Audio Library, Pixabay Music, Free Music Archive)
  hoặc nhạc của chính bạn. Không đưa nhạc có bản quyền lên đây.
